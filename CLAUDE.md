# Repo guide

This repository holds several separate projects, one per folder.

- **Patch** (AI garden helper app for Australian gardeners, Expo / React Native):
  lives in `patch/`. Before doing any work on Patch, read `patch/CLAUDE.md` in
  full. It is the project brief and the source of truth.
- Other folders (`quiet-table/`, `clip-forge/`, `inside-the-sip/`, etc.) are
  unrelated projects; the Patch brief does not apply to them.
