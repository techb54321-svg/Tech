# Hazel brand

| File | Use |
| --- | --- |
| `hazel-logo-on-dark.svg` / `.png` | Logo for dark backgrounds (ivory wordmark) |
| `hazel-logo-on-light.svg` / `.png` | Logo for light backgrounds (dark brown wordmark) |
| `hazel-mark.svg` | The hazelnut on its own, for small spaces |
| `hazel-app-icon.svg` / `.png` | App icon (1024 px PNG) |

## The mark

A flat hazelnut: warm brown with a darker side for shape and a pale base, which is what makes a hazelnut read as a
hazelnut. A two-tone hazel leaf on a short stem. No outlines, gradients or shine.

## Colours

| Name | Hex | Where |
| --- | --- | --- |
| Charcoal | `#111318` | App background, icon background |
| Ivory | `#f3efe7` | Wordmark on dark |
| Ink | `#2b1d14` | Wordmark on light |
| Gold | `#d8b46a` | Accents, primary button |
| Hazel | `#c98a4b` / `#a96a33` | Nut |
| Shell base | `#f1d9b5` | Nut base |
| Leaf | `#7ea866` / `#5f8c4b` | Leaf |
| Stem | `#6f4a2a` | Stem |

## Type

The wordmark is **Fraunces SemiBold** (display optical size) by Undercase Type, under the SIL Open Font Licence
1.1, converted to outlines. The app's own text stays in **Atkinson Hyperlegible**, chosen for readability.

## Rules

- Leave clear space around the logo of at least the width of the leaf.
- Do not recolour the hazelnut, stretch the logo, add shadows or outlines, or set "Hazel" in another font.
- Below about 24 px use the mark on its own, without the wordmark.

All of these files are drawn by `node scripts/make-brand.mjs` from `src/brand/hazel.json`.
