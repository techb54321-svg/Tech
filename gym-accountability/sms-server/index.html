Weekly text message setup

Ten minutes, once. After this your referee gets one text a week with your verdict, sent by a tiny free server that belongs to you, whether or not you ever open the app again. Your referee installs nothing. You run out of excuses.

What your referee will receive

Ironclad weekly: Alex went to the gym 3/3 days (Mon, Wed, Fri) in the week of Mon Nov 9–Sun Nov 15. VERDICT: PASS. Streak: 4 week(s). Deposit intact: $200.

Ironclad weekly: Alex went to the gym 1/3 days (Tue) in the week of Mon Nov 9–Sun Nov 15. VERDICT: FAIL. $50 is forfeited from the deposit: send it to the Flat Earth Society and keep the receipt. Deposit left: $150.

If your phone never reports in a week, the text still goes out and says so, so silence cannot hide a missed week.

Part 1 · Twilio (sends the texts)

  1. Go to twilio.com and create a free trial account. Verify your own phone when asked.
  2. On the Console home page, click Get a trial phone number. Copy that number (it starts with +). This is TWILIO_FROM.
  3. Trial accounts can only text numbers you have verified. Open Phone Numbers → Manage → Verified Caller IDs → Add, enter your referee's number, and ask them to read you the code Twilio sends. Enter it. Done once.
  4. Back on the Console home page, copy the Account SID and the Auth Token (tap Show).

The trial adds "Sent from your Twilio trial account" to each text. Upgrading removes it and costs about a dollar a month plus under a cent per text, but it is not required.

Part 2 · Cloudflare (your free server)

  1. Go to dash.cloudflare.com and create a free account.
  2. In the left menu open Workers & Pages → Create → Create Worker. Name it ironclad-sms and tap Deploy.
  3. Tap Edit code, select everything in the editor and delete it, then paste the code from the button below and tap Deploy.

  4. Create the storage: left menu Storage & Databases → KV → Create, name it ironclad. Then go back to your worker: Settings → Bindings → Add → KV namespace. Variable name STATE, namespace ironclad. Save.
  5. Still in Settings → Variables and Secrets, add these four, each with type Secret:
    • TWILIO_ACCOUNT_SID — from Part 1
    • TWILIO_AUTH_TOKEN — from Part 1
    • TWILIO_FROM — your Twilio number, with the +
    • APP_SECRET — invent a long password. You will paste the same one into the app.

  6. Settings → Triggers → Cron Triggers → Add, and enter 0 * * * *. This wakes the server once an hour; it sends the text only at the hour you choose in the app.
  7. Copy your worker's address from the top of its page (it ends in .workers.dev) and open it in a browser. You should see a status page with every line green.

Part 3 · The app

  1. Open the app, Settings → Edit contract.
  2. Make sure the referee's phone number includes the country code, for example +1 555 000 0000.
  3. Under How the referee hears from you choose Automatic → Weekly text message, paste the server address and the secret, and pick the hour the weekly text should arrive.
  4. Tap Send a test message. Your referee should get a text within seconds. Then Save changes.

The text goes out at the hour you pick on the first day of each new week, summarising the week that just closed, so the result is final when it is sent.

If something does not work

  • Status page shows a red line: that setting is missing on the worker. Add it under Settings and tap Deploy if asked.
  • Test says "Unverified number": finish step 3 of Part 1 for the referee's number, or upgrade the Twilio account.
  • Test says "wrong secret": the APP_SECRET on the worker and in the app do not match exactly.
  • No weekly text arrived: check the cron trigger exists, and open the status page; it shows when the last weekly text was sent.

Technical users can instead run npx wrangler deploy from the sms-server folder of the repository; see wrangler.toml.
