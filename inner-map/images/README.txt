The four levels in this folder are generated:

    node tools/make-art.mjs

  01-valley.svg   the whole knitted valley, river running through it
  02-village.svg  closer, houses readable
  03-house.svg    closer still, doors and windows visible
  04-bench.svg    the Keymaker at her bench

To use your own artwork instead, put four images of the same aspect ratio here
and point `file` in ../src/world.js at them. Draw each one at the size it will
be read at — see the table in ../README.md.
